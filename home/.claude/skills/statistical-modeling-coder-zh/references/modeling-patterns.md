# 建模模式

本文件用于实现统计模型层。

## 隐变量或份额估计

当目标变量不可直接观测，但已知结果能约束它时：

1. 把已知结果翻译成不等式、可行条件或筛选条件。
2. 在正确支持集上生成候选隐变量，比如份额问题用单纯形。
3. 用条件筛掉不可行样本。
4. 对可行样本汇总上下界、均值、标准差、区间宽度、熵和决策边际。
5. 先保证可行性，再做时间平滑。

推荐保留稳健 fallback：

- 正式采样器太脆弱时，用蒙特卡罗或拒绝采样；
- 贝叶斯工具不可用时，用 bootstrap 或多随机种子重复仿真；
- 记录抽样次数和随机种子。

份额向量常见错误：

- 所有轨迹被平滑成几乎直线；
- 最后阶段份额没有在真实分母集合上加和；
- 结构性不适用对象仍然拿到份额；
- 曲线跳变来自分母变化，而不是隐变量真实变化。

## 反事实机制比较

比较规则时，把每种规则写成输入契约相同的纯函数：

- 对齐后的面板表或分组表；
- 观测信号 A；
- 观测或隐藏信号 B；
- 规则参数，比如权重、阈值、触发条件。

有用输出包括：

- 每个组/时间下各规则的详细决策；
- 按组和时间汇总的差异率；
- 规则输出之间的排名一致性或 Spearman 相关；
- 偏向或支配指标，比如最终分数与某个信号的相关性；
- 边界样本、反常样本、高影响样本的案例表。

当一种规则用排名、另一种规则用百分比时，要解释数学差异：

- 排名聚合压缩极端量级差异；
- 百分比聚合保留量级差异，可能放大长尾支配；
- bottom-k、阈值、复核、覆盖机制都是条件过滤器，如果对象从不进入触发集合，它们可能失效。

## 特征效应分析

当题目问“哪些因素影响结果”或“不同通道影响是否相同”时：

1. 建立对齐后的通道目标，比如专家侧/公众侧归一化结果，或传感器侧/结果侧指标。
2. 两个通道使用同一行集合。
3. 目标是组成数据时，先做适当变换。
4. 先拟合可解释模型：线性模型、混合效应、正则化回归、带区间的分组汇总。
5. 只有在题目确实需要异质偏好机制时，再加混合专家或门控模型。

报告内容：

- 标准化系数或边际效应；
- 置信区间或可信区间；
- 用户要求时报告 p 值或后验符号概率；
- 通道差异效应，例如 `channel_b_effect - channel_a_effect`;
- 可用实体特征的分组汇总，例如年龄、行业、搭档、地区、处理组或类别。

对高基数类别，优先使用部分汇聚、正则化或带最小样本量检查的分组汇总，避免过拟合。

## 验证指标

隐藏变量估计至少给出多视角验证：

- 点估计复现率：最终估计或后验均值能否复现已知结果；
- 后验一致性概率：样本中能复现已知结果的比例；
- 精确决策过严时，给出二分类或多分类状态准确率；
- 决策边际分布；
- 后验标准差；
- 可信区间宽度；
- 熵或集中度指标；
- 对随机种子、权重、先验、阈值、抽样次数的稳健性。

不要通过偷偷改指标定义来“刷高”结果。如果精确复现率低，要如实报告，并补充能解释模型仍然有用的辅助指标。

## 调试循环

当用户说“模型看着不对”时：

1. 检查分母集合构造。
2. 检查输出是否满足必要加和约束。
3. 检查排名方向。
4. 检查结构性不适用行是否还在被绘图或打分。
5. 手工对比早期、中期、后期样本。
6. 构造一个期望结果显然的小例子。
7. 最后再调平滑、先验、权重或抽样参数。
