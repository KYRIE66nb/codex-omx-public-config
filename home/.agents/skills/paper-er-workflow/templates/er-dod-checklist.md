# ER图与数据库设计验收清单（DoD）

## A. 概念ER图
- [ ] 实体是否完整覆盖核心业务对象
- [ ] 每条关系是否标注基数（1:1 / 1:N / N:M）
- [ ] 是否标注参与约束（可选/必选）
- [ ] 图题与图号是否规范（如：图4-11 系统ER图）

## B. 逻辑结构设计
- [ ] 是否给出“ER关系 -> 关系模式”映射
- [ ] N:M关系是否拆分中间表
- [ ] 每个外键是否明确指向主表主键
- [ ] 是否说明删除/更新级联策略

## C. 物理表设计
- [ ] 每张核心表是否给出主键（PK）
- [ ] 外键（FK）是否完整
- [ ] 唯一约束、非空约束是否明确
- [ ] 默认值是否说明
- [ ] 索引是否标注（普通/唯一/联合）
- [ ] 字段命名是否统一（`id`、`xxx_id`）

## D. 性能与一致性
- [ ] 高频查询字段是否配置索引并说明原因
- [ ] 关键事务场景是否说明一致性策略
- [ ] 是否避免明显数据冗余和更新异常

## E. 可读性与美观
- [ ] 总图 + 子图分层是否清晰
- [ ] 连线是否尽量避免交叉
- [ ] 同类元素样式是否一致（线宽/字号/配色）
- [ ] 关系标签是否为业务语义（如“提交”“审核”“包含”）
