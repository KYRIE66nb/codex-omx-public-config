# Student CS command reference

Run from repo root.

## Template generation

- `./bin/student-cs offer`
- `./bin/student-cs daily-content`
- `./bin/student-cs study-blocks`
- `./bin/student-cs weekly-review`
- `./bin/student-cs bug-report`
- `./bin/student-cs design-doc`
- `./bin/student-cs paper-checklist`

## Memory

- Build index: `./bin/student-cs memory-index`
- Query index: `./bin/student-cs memory-query "moltbook"`

## NL router

- `./bin/student-cs-nl "search memory for moltbook"`
- `./bin/student-cs-nl "weekly review"`
